# 合规文档（Compliance）

> 本文档记录本项目的法律与平台合规底线与实现护栏。**它是对通用实践的经验性梳理，不构成法律意见**；
> 如涉及具体司法管辖区的合规判断，请以专业法律意见为准。

---

## 1. 核心底线（不可突破）

本项目**不提供、不托管、不链接、不生成任何受版权保护的游戏资源**（MPQ、调色板、精灵、
音频、放大后的贴图等）。所有解码、查看、复原、导出、放大功能，都依赖使用者本地已有的
**官方正版**文件（含 `DIABDAT.MPQ` 等）。没有正版文件，与游戏内容相关的功能无法运行。

这一底线同时覆盖了：

- **版权合规**：仓库与 release 不含任何游戏素材；
- **平台合规（GitHub / Gitee）**：没有可供自动扫描或人工投诉命中的受版权内容；
- **商标**：以中性、描述性方式指名游戏（如「Diablo / Hellfire 资源工具」），不暗示官方授权或背书。

## 2. AI 高清化（补值超分）的三层风险与对策

「AI 补值高清化」指对解码出的精灵/关卡帧做超分辨率放大（image-to-image super-resolution）。
它复用第 1 节的底线，但新增三层需专门压住的风险。

### 2.1 输出物（放大后的图）版权层

- 放大产物是对使用者自有正版拷贝提取物的**衍生处理**，仍属原游戏的衍生品，版权归原持有人。
- 项目**只做本地工具、不在任何地方分发产物**：放大在用户本机、从用户自己的提取帧出图，产物留用户本地。
- 用户将放大图二次传播是其自身行为，项目不捆绑、不托管任何资源包。
- **残差风险**：放大图作为衍生品，用户分享时仍受原游戏版权约束。免责声明需明确：
  「产出物为衍生品，用户自行承担其使用/传播责任，本项目不授予任何游戏素材的重分发权利。」

### 2.2 模型权重（AI 模型）出处层 —— 最易踩的坑

超分依赖训练好的模型（waifu2x / ESRGAN 系等）。风险不在「用」，而在**把权重打进仓库**：

- 社区模型的训练集常含受版权素材（部分含游戏图）。一旦提交进 git，项目即背负「该权重训练数据是否合规」
  这一无法控制的连带责任，也更易被扫描/投诉盯上。
- **合规解法：绝不内置权重。** 放大在**浏览器端（WASM / WebGL）**执行，权重由**用户自备本地路径**，
  或用户从模型原出处自行下载后指向它。仓库因此零权重、零资源，模型出处责任完全在用户。

### 2.3 超分 vs 生成 —— 决定风险高低

- **安全区：图像到图像的超分**（对已有解码帧放大、补细节）。确定性增强，不「创造」新角色表达，合规最稳。
- **高危区：生成式模型（diffusion / 文生图）去「重绘」Diablo 角色**。等于让 AI 生成受版权保护的角色形象，
  风险显著上升，且易触商标/角色肖像雷区。**本项目明确不做**——功能严格限定为「对提取帧的超分增强」，
  而非「AI 生成暗黑美术」。

## 3. 平台（GitHub / Gitee）风控

- 超分**不破解任何技术保护措施**；MPQ 走 StormLib 属公开的互操作实现，非 DRM 破解，
  不触发 DMCA 1201 反规避条款。
- GitHub 的禁用项主要是「规避技术措施」与「散播恶意代码」——纯超分工具两者皆不沾。
  自动扫描主要查二进制/资源，仓库零权重零资源时几乎无命中可能。
- 真正的人文 DMCA 风险只来自「仓库内出现受版权内容」；只要不分发图/权重，即无触发源。
- 商标：继续用中性表述（「更高分辨率导出 / AI 辅助放大」），**不称「HD Diablo」或暗示官方授权**。

## 4. 实现护栏清单（落地 A + 高清化时必须遵守）

1. 仓库与 release **绝不打包权重、样本图、放大产物**。
2. 放大**仅本地运行**：输入为用户提取帧，输出留用户本地，项目不中转、不托管。
3. 默认支持**用户自备模型路径**；权重来源责任在用户。
4. 功能严格限定为**超分（image-to-image）**，**不引入生成式重绘**。
5. README / 插件文档显式声明：产出物为衍生品，项目不授予游戏素材重分发权；只服务「自备正版」用户。
6. demo / GIF 用「本人正版拷贝渲染」的个案展示，不附带可下载资源包。
7. 保留对权利方投诉的快速响应 / 下架流程（遵守 takedown）。

## 5. 多游戏插件（方向 B）的额外注意

若后续引入其他游戏的导入/导出插件（仍不提供任何资源）：

- 插件系统本身利于风险隔离；**高敏感游戏的插件应拆到独立仓库 / 独立 registry**，主仓库只留 HF 核心 + 插件加载器，
  以限制「爆炸半径」。
- 仅支持**开放 / 非加密**格式；**禁止**任何解密受保护技术措施（反规避）的插件。
- 贡献策略明确拒绝 circumvention 类提交。
- 开局优先「MOD 文化友好、厂商不激进」的老 PC 格式（如 Doom / Quake / Build 引擎），
  **避开维权激进的 IP 方**（如任天堂）以降低人工 DMCA 概率。
