以下是《暗黑破坏神1》本体与《地狱火》资料片中出现的技能与法术整理。由于部分法术同时存在于玩家和怪物侧，而怪物还有一些专属能力，因此按**玩家可学法术**、**角色固有技能**、**怪物法术与能力**三部分来组织，这样会更清楚。

---

### 🧙 玩家可学法术（通过法术书/卷轴/法杖）

《暗黑1》本体有4页法术书，《地狱火》增加了第5页。同一法术书重复阅读可以提升法术等级（受“魔法”属性限制）。

#### 《地狱火》新增法术（第五页 + 额外法术）

《地狱火》在第五页法术书增加了多个新法术，同时还有一些只能从卷轴/法杖获得的法术。

| 法术（中文/常用译名） | 英文原名 | 获取方式 / 说明 |
| :--- | :--- | :--- |
| 闪电墙 | Lightning Wall | 制造一道持续伤害的闪电屏障 |
| 献祭/自爆 | Immolation | 以自身为中心向四周放出火球 |
| 传送（变体）/扭曲 | Warp | 地狱火新增的传送类法术 |
| 反射 | Reflect | 反弹部分伤害/法术 |
| 狂暴 | Berserk | 针对敌人施放；野蛮人相关法术 |
| 火焰之环 | Ring of Fire | 在自身周围放出一圈火焰 |
| 搜寻 | Search | 僧侣的固有技能，也可作为法术出现 |
| 小丑 | Jester | **仅法杖**，随机效果法术 |
| 法师 | Magi | **仅法杖** |
| 法力 | Mana | **仅法杖**，直接恢复/操纵法力 |
| 天启 | Apocalypse | 在地狱火中**可以通过法术书学习**（不再仅限于卷轴/法杖） |
| 新星 | Nova | 在地狱火中**可以通过法术书学习** |

此外，《地狱火》还加入了**闪电墙、献祭、扭曲、反射、狂暴、火焰之环、搜寻**等法术，使法术总数明显多于本体。

### 🛡️ 角色固有技能（不消耗法力，随职业固定）

这些技能不是“法术书”法术，但属于角色能力的一部分，从1级开始即可使用。

| 角色 | 固有技能 | 效果 |
| :--- | :--- | :--- |
| **战士** | 修理武器 | 恢复物品耐久，但最大耐久会略微下降 |
| **浪人** | 侦测/解除陷阱 | 识别门和箱子上的陷阱，并有机会解除 |
| **法师** | 法杖充能 | 为法杖恢复充能次数，但最大充能数会减少 |
| **僧侣**（地狱火） | 搜寻 | 自动搜寻周围物品，防止遗漏掉落 |
| **吟游诗人**（地狱火） | 鉴定 | 无需卷轴或凯恩即可鉴定魔法物品 |
| **野蛮人**（地狱火） | 狂暴 | 12秒内提升力量/敏捷/体质，随后进入12秒的虚弱惩罚期 |

### 👹 怪物法术、特殊攻击与词缀能力

怪物侧的能力构成比较复杂：一部分怪物直接使用玩家法术（如火球、闪光），另一部分拥有玩家无法学习的专属法术，还有一些是“怪物词缀”带来的特殊能力。

#### 怪物使用的“玩家法术”（或近似版本）

以下法术在怪物侧也会出现，但伤害公式和表现可能与玩家版本不同：

- **火球（Fireball）** ：大主教（Advocate）等施法怪物使用。
- **闪光（Flash）** ：大主教（Advocate）使用。
- **闪电（Lightning）** ：部分怪物（如Red Storm）投掷闪电。
- **地狱之火（Inferno）** ：矿坑恶魔等使用。
- **充能弹（Charged Bolt）** ：部分施法怪物使用。
- **火墙/火焰波/新星**：部分高阶施法怪物可能使用对应效果。

#### 怪物专属法术/特殊攻击（包含《地狱火》新增）

Jarulf攻略的4.2.1/4.2.2节专门列出了怪物法术。以下为可确认的怪物专属能力：

| 法术/攻击 | 使用怪物（示例） | 类型/说明 |
| :--- | :--- | :--- |
| **魔法弹（Magic Attack）** | 骨魔（Bone Demon）、巫妖（Lich）、大巫妖（Arch Lich） | 魔法伤害，可格挡 |
| **岩浆球（Magma Ball）** | 岩浆恶魔（Magma Demon）等 | 火焰伤害，可格挡 |
| **吐痰攻击（Spit Attack）** | 喷吐恐惧（Spitting Terrors）等 | 魔法伤害；部分版本会留下酸液池 |
| **死灵球（Necromorb）** | 特定不死施法者 | 魔法伤害，可格挡 |
| **心灵球（Psychorb）** | 特定施法者 | 魔法伤害，可格挡 |
| **骨魔攻击（Bone Demon attack）** | 骨魔 | 魔法伤害，可格挡 |
| **大巫妖攻击（Arch Lich attack）** | 大巫妖 | 魔法伤害，可格挡 |
| **法力吸取/眩晕** | 手指法师（Finger Mage） | 追踪弹吸取法力，并使目标眩晕 |

> **本项目 `spell.list` 的覆盖情况**：玩家侧 51 条（含未使用的 4 个 ID 与 5 个陷阱符文）全部输出；
> 怪物侧 25 条 = `GetMissileType()` 的 16 类 AI（含 `unique_monstdat` 唯一怪带来的 `AcidUnique`、
> `LazarusSuccubus`）+ 在 AI 函数内直接 `AddMissile` 的 9 个形态（Counselor 按智力 0..3 →
> Firebolt/ChargedBolt/LightningControl/Fireball，外加近身双层 Flash；Familiar → Lightning；
> Gloom → Rhino 冲撞；Mega → InfernoControl；Hork Demon → HorkSpawn）。上表中的“大主教火球/闪光”
> 即对应 Counselor 的 Fireball 与 Flash 两条。另有 `abilities[]` 3 条引擎级怪物特殊能力：
> **瞬移**（`MT_BLINK` 受重击 `Teleport()`，即下表的 Teleporter）、**死亡酸池**（酸液怪尸体
> 留 `AcidPuddle`）、**隐身**（潜行系 `MFLAG_HIDDEN`）。
>
> **需要更正的下表内容**：Teleporter/Thunderstorm/Waller/Vortex/Shielding 是**暗黑破坏神 2** 的
> 怪物词缀，DevilutionX（暗黑 1 / 地狱火）引擎中并不存在。其中只有“传送”有对应实现（`MT_BLINK`
> 受击瞬移）；**闪电风暴 / 筑墙 / 漩涡 / 护盾在 `Source/` 里完全没有对应代码**，因此 `spell.list`
> 不会伪造这些条目。陷阱类法术效果目前仍未纳入。

#### 怪物词缀能力（Champion/Unique怪物）

这些不是“法术书”法术，但属于怪物在战斗中会使用的特殊技能：

- **传送（Teleporter）** ：怪物瞬间消失并出现在别处。
- **闪电风暴（Thunderstorm）** ：召唤一道缓慢追踪玩家的闪电，持续造成伤害。
- **筑墙（Waller）** ：制造墙壁困住玩家或阻挡路径。
- **漩涡（Vortex）** ：将玩家拉向怪物，打断攻击。
- **护盾（Shielding）** ：为同组怪物提供防护。
- **召唤/筑墙组合**：冠军/稀有怪物会以更复杂的方式使用筑墙能力。

> **补充说明**：陷阱（Traps）在游戏数据中也属于“法术效果”的一部分，包括箭矢、火焰箭、新星、火焰之环、法力吸取、分解等，但它们属于环境机关而非怪物主动施法，因此未列入上表。

### 💎 总结

如果要一句话概括：**玩家侧的法术核心清单以4页（本体）+第5页（地狱火）法术书为骨架，怪物侧则以“通用法术复用 + 专属魔法攻击 + 词缀能力”三层叠加。** 最完整、最权威的单一资料源是 **Jarulf's Guide to Diablo and Hellfire**，其第4.1节覆盖玩家法术，第4.2节覆盖怪物法术，第4.3节涉及陷阱，是研究这款游戏机制时几乎无法绕开的参考。
