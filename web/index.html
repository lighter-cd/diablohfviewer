角色查看器（按公式 plrgfx\{职业}\{c}{a}{w}\{c}{a}{w}{动作}.cl2 拼路径）
选职业/动作后自动列出该职业真实存在的盔甲与武器组合；切换即解码并播放。
怪物 / NPC 查看器（数据表枚举：monstdat.tsv / towners.tsv）
怪物按 monstdat 的动画字母枚举（Stand/Walk/Attack/Hit/Death/Special）；NPC 为单方向 .cel 精灵。选择即解码并播放，方向数取自解码返回的 directions。
技能 / 战斗查看器（同屏：玩家 + 怪物 + 全阶段效果）
「方向」滑块以施放者为中心旋转整场：目标落在施放者朝向的方位并回身面向施放者，两者位置与朝向同步重算。四个阶段都在当前方向内播完，播放不切换方向。「▶ 播放」连走 施法 → 投射 → 命中 → debuff，阶段按钮可单独查看；debuff 用 TRN 对目标做近似着色。
场景查看器（scene.list / scene.build · 完整等距关卡）
选场景 → 加载：后端用 DevilutionX 两遍绘制（地板菱形 + 墙体）复原完整场景，返回 PNG 预览 + 对齐的叠加层。拖拽平移、滑块/滚轮缩放。红色=Solid，蓝色=透明，黄色=BlockLight。初始场景为 Tristram 城镇。
