实体查看器（左侧下拉切换 玩家角色 / 怪物 / NPC）
选职业/动作后自动列出该职业真实存在的盔甲与武器组合；切换即解码并播放。
怪物按 monstdat 的动画字母枚举（Stand/Walk/Attack/Hit/Death/Special）；NPC 为单方向 .cel 精灵。选择即解码并播放，方向数取自解码返回的 directions。
技能 / 战斗查看器（同屏：玩家 + 怪物 + 全阶段效果）
「方向」滑块以施放者为中心旋转整场：目标落在施放者朝向的方位并回身面向施放者，两者位置与朝向同步重算。四个阶段都在当前方向内播完，播放不切换方向。「▶ 播放」连走 施法 → 投射 → 命中 → debuff，阶段按钮可单独查看；debuff 用 TRN 对目标做近似着色。
场景查看器（scene.list / scene.build · 完整等距关卡）
选场景 → 立即加载：后端用 DevilutionX 两遍绘制（地板菱形 + 墙体）复原完整场景，返回 PNG 预览 + 对齐的叠加层。拖拽平移、下拉或滚轮缩放（支持 0.25×/0.5× 整体预览，缩放时保持地图中心）。切换「光照」会在有/无光照两种结果间复用后端缓存。红色=Solid，蓝色=透明，黄色=BlockLight。「清除地图缓存」可删除已生成的场景图并强制下次重新生成。
界面布局查看器（ui.list / ui.build · 真实 MPQ 美术合成）
后端 ui.build 用真实 MPQ 美术（背景 PCX / 面板 CEL / 血蓝球 / 按钮 CLX）按 DevilutionX 坐标合成 640×480 底图，并生成对齐的元素框叠加层 PNG。文字由前端用系统字体按布局字段近似绘制（非游戏原版位图字体，可关闭核对纯美术底图）。从「元素」下拉框选中任一元素，即在下方查看类型 / 矩形 / 引用资源 / 源码位置等详情，并在画面上高亮对应元素框；不再使用鼠标悬停。
